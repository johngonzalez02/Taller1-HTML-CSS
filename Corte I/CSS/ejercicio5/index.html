Propiedad Display

Elementos div (normalmente son block)

Div 1 - display: block
Div 2 - display: inline
Div 3 - display: inline-block

Elementos span (normalmente son inline)

Span 1 - display: block Span 2 - display: inline Span 3 - display: none (no debería verse)

Explicación de diferencias observadas

Al aplicar display: block, el elemento ocupa todo el ancho disponible y siempre empieza en una nueva línea. Con display: inline, el elemento solo ocupa el espacio de su contenido y se ubica en la misma línea que los elementos vecinos, sin permitir definir ancho o alto. Con display: inline-block, el elemento se comporta como inline (se ubica en la misma línea) pero sí permite definir ancho y alto, como block. Finalmente, display: none oculta completamente el elemento, como si no existiera en la página.
